# 🎮 Gamora

> **Your next gaming hangout.**

Gamora is a gaming platform where you can find and play different games in one place. The main goal is to keep things simple, fast, and fun while giving the website a modern Gen-Z look.

This project is still being worked on, so new games, features, and improvements will be added over time.

## ✨ What’s Inside?

* 🎮 Multiple games in one place
* ⚡ Fast and responsive interface
* 📱 Works on phones, tablets, and desktops
* 🎯 Easy navigation
* 🌙 Modern dark/Gen-Z inspired design
* 🚀 Designed so more games and features can be added easily

## 🚀 Running Gamora

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### Open the project

```bash
cd YOUR_REPOSITORY
```

You can simply open `index.html` in your browser.

For development, I recommend using **Live Server** in VS Code.
